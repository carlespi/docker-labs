# Docker Hands-On Labs

A collection of hands-on Docker labs focused on container management, image creation, networking, storage, and deployment.

Each lab includes practical exercises, commands, and validation steps.

## Labs

Labs are organized into numbered directories (`lab01`, `lab02`, etc.). Each directory contains its own documentation and supporting files.

## Technologies

Docker, Linux, AWS EC2, Git, and GitHub.

## Getting Started

```bash
git clone git@github.com:carlespi/docker-labs.git
cd docker-labs
```

Refer to each lab's README for instructions.
